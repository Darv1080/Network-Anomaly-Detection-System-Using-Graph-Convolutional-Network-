This electronic document presents a study on the implementation of the Graph Convolutional Network (GCN) algorithm for detecting anomalies in computer networks. As cyberattacks become increasingly sophisticated and distributed, ensuring network security has become a critical challenge for organizations and individuals. Although various Machine Learning (ML) algorithms have demonstrated high detection accuracy, most conventional approaches treat network traffic as isolated tabular data, thereby overlooking the structural relationships among network entities. To address this limitation, this study proposes the use of GCN, which leverages graph-based representations to capture topological information and learn hidden relational patterns between interconnected nodes. By aggregating feature information from neighboring nodes within the network topology, the proposed model is expected to improve anomaly detection performance, particularly for complex and distributed attack scenarios. The effectiveness of the approach is evaluated through comprehensive experiments, demonstrating that GCN enhances detection accuracy, robustness, and generalization capability compared to traditional machine learning methods while providing a more comprehensive understanding of network behavior.
